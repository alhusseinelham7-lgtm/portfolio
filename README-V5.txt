- تحسينات الأداء السابقة محفوظة.

مهم:
1) Google Analytics لا يعرض عدد الزوار داخل لوحة الإدارة نفسها؛ شاهد الأرقام الحقيقية في Google Analytics.
2) لتفعيل النشر الحقيقي من الإدارة على أي جهاز، أكمل إعداد Supabase حسب README السابق وSUPABASE-SETUP.sql.
3) sitemap.xml حالياً يستخدم رابط GitHub Pages الحالي. إذا ركّبت دوميناً خاصاً، حدّث siteUrl في الإدارة ثم يفضّل تحديث sitemap.xml للدومين الجديد.
4) لا يوجد ضمان للمركز الأول في Google. النسخة تجهز الأساس التقني؛ جودة المحتوى، المنافسة، الروابط الخارجية، وسلطة الدومين تؤثر أيضاً.
